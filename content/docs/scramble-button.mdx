title: ScrambleButton
description: A button that cycles its label through random characters before revealing the final text — like a cypher decoding itself.
---

ScrambleButton is built for generate, decrypt, roll, or randomize actions. Text scrambles through a configurable character set with an eased reveal, giving a satisfying sci-fi/cyberpunk feel.

## Usage

```tsx
import { ScrambleButton } from "@/components/evil-buttons/scramble-button";

export function GenerateButton() {
  return (
    <ScrambleButton
      idleLabel="Generate Password"
      scrambledLabel="p@ssw0rd!x9"
      duration={700}
      onClick={async () => {
        // trigger generation
      }}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `idleLabel` | `React.ReactNode` | `"Generate"` | Label before scrambling. |
| `scrambledLabel` | `React.ReactNode` | `idleLabel` | Label revealed after scramble completes. |
| `scrambleChars` | `string` | alphanumeric + symbols | Characters used during the scramble animation. |
| `duration` | `number` | `700` | Duration of the scramble animation (ms). |
| `onClick` | `(e) => void` | - | Click handler. Clicking while revealed resets. |

All other `<button>` attributes are forwarded.
