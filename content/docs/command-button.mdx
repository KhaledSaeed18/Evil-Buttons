CommandButton is useful for command palettes, dashboards, editors, and dev tools. It shows a shortcut hint and runs `onCommand` when the shortcut is pressed.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/command-button</Cmd>

## Usage

```tsx
import { CommandButton } from "@/components/evil-buttons/command-button";

export function SaveButton() {
  return (
    <CommandButton shortcut="mod+s" onCommand={() => save()}>
      Save
    </CommandButton>
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `shortcut` | `string` | `"mod+s"` | Shortcut tokens joined by `+`, e.g. `mod+k` or `shift+?`. |
| `onCommand` | `() => void` | - | Called when the shortcut is pressed. |
| `preventDefault` | `boolean` | `true` | Prevents the browser default for the shortcut. |
| `showShortcut` | `boolean` | `true` | Shows the shortcut badge. |

All other `<button>` attributes are forwarded.
