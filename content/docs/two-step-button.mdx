TwoStepButton is a compact confirmation pattern for actions that need intent but do not deserve a modal. The first click arms the button for a short time; the second click confirms.

## Usage

```tsx
import { TwoStepButton } from "@/components/evil-buttons/two-step-button";

export function DeployButton() {
  return (
    <TwoStepButton
      idleLabel="Deploy"
      armedLabel="Click again to deploy"
      confirmedLabel="Deployed"
      armDuration={2600}
      onConfirm={() => deploy()}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onConfirm` | `() => void` | - | Called on the second click. |
| `onArm` | `() => void` | - | Called on the first click. |
| `idleLabel` | `React.ReactNode` | `"Deploy"` | Initial label. |
| `armedLabel` | `React.ReactNode` | `"Click again"` | Label while armed. |
| `confirmedLabel` | `React.ReactNode` | `"Confirmed"` | Label after confirmation. |
| `armDuration` | `number` | `2600` | Milliseconds before the armed state resets. |
| `resetAfter` | `number` | `1200` | Milliseconds before resetting after confirmation. |
| `destructive` | `boolean` | `false` | Uses a destructive color treatment. |

All other `<button>` attributes are forwarded.
