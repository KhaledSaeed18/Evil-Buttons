BreatheButton adds a subtle, meditative pulse to your interface. The button slowly scales in and out like a breath, with a glowing overlay that fades in rhythm. On hover it perks up, and on click it responds with a quick heartbeat.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/breathe-button</Cmd>

## Usage

```tsx
import { BreatheButton } from "@/components/evil-buttons/breathe-button";

export function MeditateButton() {
  return (
    <BreatheButton speed={4000} amplitude={1.03}>
      Pause
    </BreatheButton>
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `speed` | `number` | `3600` | Duration of one full breathe cycle (ms). |
| `amplitude` | `number` | `1.025` | How much the button scales during inhale. |
| `children` | `React.ReactNode` | `"Breathe"` | Button label. |

All other `<button>` attributes are forwarded.

## Registry

The registry item includes `components/evil-buttons/breathe-button.tsx` and installs `motion`, `clsx`, and `tailwind-merge` as dependencies.
