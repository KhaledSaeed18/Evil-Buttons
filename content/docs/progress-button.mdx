ProgressButton is for uploads, exports, imports, syncs, and generated files where a spinner is too vague. Pass a progress value from `0` to `100` and the button renders a fill layer behind the label.

## Install

Add the item with the shadcn CLI.

<Cmd>@evilbuttons/progress-button</Cmd>

## Usage

```tsx
import { ProgressButton } from "@/components/evil-buttons/progress-button";

export function ExportButton({ progress }: { progress: number }) {
  return (
    <ProgressButton
      progress={progress}
      idleLabel="Export"
      runningLabel="Exporting"
      completeLabel="Exported"
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `progress` | `number` | `0` | Progress from `0` to `100`. |
| `status` | `"idle" \| "running" \| "complete" \| "error"` | derived | Explicit visual state. |
| `idleLabel` | `React.ReactNode` | `"Export"` | Initial label. |
| `runningLabel` | `React.ReactNode` | `"Exporting"` | Label while running. |
| `completeLabel` | `React.ReactNode` | `"Complete"` | Label after completion. |
| `errorLabel` | `React.ReactNode` | `"Failed"` | Label on error. |
| `showPercent` | `boolean` | `true` | Shows the numeric progress while running. |

All other `<button>` attributes are forwarded.
